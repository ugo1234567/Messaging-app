Unity Messaging App

This project is a messaging application developed using the Unity game engine. The application is designed to allow users to communicate with each other through a messaging interface.

The project uses Unity and C# scripts to manage the app's functionality and UI.

Features

UI for the messaging application

User list management

Chat management

Server connection functionality

Technologies Used

Game Engine: Unity

Programming Language: C#

Development Environment: Visual Studio and Visual Studio Code

Version Control: Git and GitHub

Large File Management: Git LFS
